# OpenProcessing · Interaction Lab 20

Games 10 个 + Particles 10 个。全部取自 OpenProcessing 的公开代码，保留原版与署名，增强移动端互动和挑战目标。

无需构建。打开 index.html，或用 `python3 -m http.server 8000` 在本目录启动静态服务。游戏可分别打开 games/<slug>/index.html。完整 ZIP 解压后保留目录结构即可离线使用；运行库已随包提供。

- originals/：获取的原版代码，含 SHA-256 校验和来源
- games/：改编代码、展示入口、逐文件差异与说明
- standalone/：各作品独立单页 HTML，可单文件运行
- downloads/：完整包与 20 个单独 ZIP
- manifest.json 与 CREDITS.md：20 个来源和许可

未对接 Loopit API；按用户要求增强实际互动玩法。多数作品保留 CC BY-NC-SA 3.0 非商业许可。
