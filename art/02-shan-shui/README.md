# Quiet Ridges

Pull mountains out of paper. Move the sun through a landscape you shape.

## Interaction
Drag up or down to sculpt lasting ridges. Choose Move sun to relocate the sun.

Model: Persistent terrain brush. Scene-specific input, persistent state and simulation are in assets/art/interactions.js. Rendering and interpolation are shared; there is no generic touch-repulsion interaction.

Spring interpolation derived from Mouse Twitch / maks: https://openprocessing.org/@maksss/3026808 . New shape, input and simulation authored for this collection. CC BY-NC-SA 3.0, https://creativecommons.org/licenses/by-nc-sa/3.0/ . Original source: originals/12-particle-twitch/mySketch.
