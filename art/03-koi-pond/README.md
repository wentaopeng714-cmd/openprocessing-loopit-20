# Koi Letters

Draw with food. Three fish turn, follow the trail, and eat what you leave.

## Interaction
Tap to drop food. Drag to leave a trail. Wait for the fish to find it.

Model: Autonomous feeding and steering. Scene-specific input, persistent state and simulation are in assets/art/interactions.js. Rendering and interpolation are shared; there is no generic touch-repulsion interaction.

Spring interpolation derived from Mouse Twitch / maks: https://openprocessing.org/@maksss/3026808 . New shape, input and simulation authored for this collection. CC BY-NC-SA 3.0, https://creativecommons.org/licenses/by-nc-sa/3.0/ . Original source: originals/12-particle-twitch/mySketch.
