# Thread by Thread

A loom remembers your hands. Lay colored threads and cross them into cloth.

## Interaction
Draw across the loom to weave a thread. Change thread color, or undo one strand.

Model: Persistent weaving with over-under crossings. Scene-specific input, persistent state and simulation are in assets/art/interactions.js. Rendering and interpolation are shared; there is no generic touch-repulsion interaction.
