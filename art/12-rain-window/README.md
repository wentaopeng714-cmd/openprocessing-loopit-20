# Window Weather

Clear the mist with your hand. Let the glass gently cloud over again.

## Interaction
Wipe the window with a drag. Cleared paths remain, then mist slowly returns.

Model: Fog erasure and condensation. Scene-specific input, persistent state and simulation are in assets/art/interactions.js. Rendering and interpolation are shared; there is no generic touch-repulsion interaction.

Spring interpolation derived from Mouse Twitch / maks: https://openprocessing.org/@maksss/3026808 . New shape, input and simulation authored for this collection. CC BY-NC-SA 3.0, https://creativecommons.org/licenses/by-nc-sa/3.0/ . Original source: originals/12-particle-twitch/mySketch.
