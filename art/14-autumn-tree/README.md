# Borrowed Autumn

A fast swipe becomes wind. Leaves fall, gather, and return with spring.

## Interaction
Swipe quickly to shake leaves loose. Tap to regrow them. Try Autumn and Spring.

Model: Wind impulses, falling leaves and regrowth. Scene-specific input, persistent state and simulation are in assets/art/interactions.js. Rendering and interpolation are shared; there is no generic touch-repulsion interaction.

Spring interpolation derived from Mouse Twitch / maks: https://openprocessing.org/@maksss/3026808 . New shape, input and simulation authored for this collection. CC BY-NC-SA 3.0, https://creativecommons.org/licenses/by-nc-sa/3.0/ . Original source: originals/12-particle-twitch/mySketch.
