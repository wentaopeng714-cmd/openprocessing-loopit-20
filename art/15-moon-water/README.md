# 月落水面

一轮颗粒质地的月亮，和很轻的水纹。伸手，把月光揉成散落的银沙。

操作：拨动月面 · 描摹月沿 · 拂过倒影。没有得分、倒计时或结束状态，可反复互动。支持多点触摸、形态散开与重组、主题变化、静止观看及保存画面。
