# Pocket Universe

Place a black hole. Deepen it, move it, and watch stars find new orbits.

## Interaction
Tap to create a gravity well. Hold to deepen it. Drag the well to reshape star orbits.

Model: Persistent gravitational wells and orbital dynamics. Scene-specific input, persistent state and simulation are in assets/art/interactions.js. Rendering and interpolation are shared; there is no generic touch-repulsion interaction.
