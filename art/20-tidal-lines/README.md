# 潮汐的线

青色海浪一层层靠近。手指穿过海面，留下一条很快被潮汐抚平的线。

操作：推开波纹 · 顺着海浪拖动 · 松手让潮水继续。没有得分、倒计时或结束状态，可反复互动。支持多点触摸、形态散开与重组、主题变化、静止观看及保存画面。
