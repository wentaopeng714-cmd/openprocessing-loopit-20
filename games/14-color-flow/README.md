# 彩流园丁

拖动扰动彩色流场，收集流经光圈的粒子；可切换调色板。

目标：80 分；时限：45 秒。开始、暂停、重玩和最佳纪录共用 `assets/lab.js`。

原作品：[ Hairy Colorful Patches ](https://openprocessing.org/@dsa157/3026685)，作者 **David April**。
