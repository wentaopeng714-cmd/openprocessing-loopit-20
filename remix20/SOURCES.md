# Twenty OpenProcessing source remixes

These adaptations retain actual code downloaded from the public source files of the linked OpenProcessing sketches. Each individual ZIP includes the unchanged original tabs, original assets when applicable, source file URLs and SHA256 hashes, a visual-code diff and the adapted code. Source algorithms are independent; only pointer/UI handling is shared.

Original author notices are retained. License identifiers were read from OpenProcessing metadata. Share-alike and attribution conditions continue to apply. **13 — Chromatic Breath retains CC BY-NC-SA and is limited to noncommercial use unless separately permitted.** The Facial Rig includes the Ray character credited to CGTarian Online School by Jason Labbe.

## Validation

Nineteen 2D works execute the actual vendored p5.js in a simulated DOM with native Canvas rendering. Checks cover Pointer Events, scene buttons, slider inputs, pause, UI hiding and viewport changes. The facial rig uses the original p5 1.3.1 OBJ loader and original deformation functions; 58 meshes load, smile changes 1,173 vertices, calm restores the mesh, and jaw dragging changes its control. Its thumbnail is a software projection of those meshes, not a WebGL screenshot. No live browser/GPU or real phone check was possible while the host Mac was locked.

See qa-runtime.json and qa-face.json. Runtime checks do not establish actual device performance. Gallery thumbnails are source renders, not browser screenshots.

## Rebuild

Run `python3 remix20/build.py`, `python3 remix20/package.py`, the Node runtime checks, then `python3 remix20/gallery.py` from the repository root. Source snapshots live in `research/op-new-20/`. The source text is preserved as downloaded; all subsequent edits are in the remix folders. p5.js LGPL notices accompany each ZIP.
