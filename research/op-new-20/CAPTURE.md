# Source capture

Source tabs were downloaded unchanged from OpenProcessing’s publicly served preview files. Their exact URLs and SHA256 hashes appear in each remix source.json. Sketch metadata, including licence identifiers, was read from the public sketch API; this capture is in the adjacent ID-metadata.json files. All 20 selected sketch IDs have source snapshots here. The Facial Rig includes its original OBJ and font files fetched from the sketch’s public fileBase.

The public API returned HTTP 429 during discovery. Requests were stopped, then metadata verification was completed after the limit cleared. No hidden source or authenticated endpoint was accessed. Screenshots were not captured from the platform because the host Mac was locked; runtime-rendered previews must not be described as platform screenshots.
